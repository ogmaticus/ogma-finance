# Пункт 3.6 — компактный бюджет, версия 1.9.7

Категории показаны компактными строками: SVG-иконка, название, расходы из лимита, полоса и состояние. Цвет полосы меняется при достижении 80% и превышении лимита. Сумма превышения явно подписана. Нажатие всей строки открывает окно ввода лимита, на телефоне — нижнюю шторку. Поле принимает точку и запятую.

Категории без расходов и без лимита свёрнуты в «Ещё N категорий». Категории с заданным нулём остаются видимыми. История операций доступна в разделе категорий и через предупреждения.

Новая проверка реальных обработчиков: строка открывает лимит нужного месяца, сумма с запятой сохраняется точно в копейках, другой месяц не меняется. Существующие проверки месяцев, возвратов, нулевых/пустых планов, копирования и ZIP сохраняются. Полный набор тестов, TypeScript, ESLint, форматирование и сборка выполняются перед публикацией; публикация производится только после их успешного завершения.

Изменены budget-ui.js, app.html, shell.css, тесты и версия оболочки. Финансовый формат, серверные записи и алгоритмы расчётов не менялись.

Ручная проверка Android/Safari не выполнена: нажатие строк, нижняя шторка/клавиатура, свёрнутые категории, оба оформления и выбор месяца.
