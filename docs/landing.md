# Мультикнопка — лендинг ogma

> **Как устроено у нас (17.10.2026).** Файлы лендинга лежат в папке `landing/` репозитория и выкладываются вместе с приложением в `/opt/finance/landing`. Caddy отдаёт их на `multiknopka.ru` (шаблон `deploy/Caddyfile.landing`): строгая CSP и `frame-ancestors 'none'` заголовком, gzip/zstd, `no-cache` для HTML/CSS/JS, неделя кэша для `fonts/` и `assets/`. `/privacy` и `/consent` переадресуются на `app.multiknopka.ru`. `www.multiknopka.ru` и мультикнопка.рф переадресуются на лендинг. Лендинг включается автоматически, когда `multiknopka.ru` указывает на сервер (переменная `DEPLOY_LANDING`, по умолчанию `multiknopka.ru`). Раздел «Публикация и CSP» ниже про nginx — справочный, у нас Caddy.


Готовый статический сайт на HTML, CSS и JavaScript (ES-модуль). Без фреймворков, сборки, npm, внешних CDN, аналитики и cookie. Все шрифты и графика уже включены в комплект.

## Концепция

Тёмная технологичная страница с крупными заголовками Rubik, текстом IBM Plex Sans и фиолетовым интерактивным ядром. Зелёный выделяет работающий модуль «Личное». Заголовок: «Деньги. Бизнес. Склад. Одна кнопка». Подзаголовок: «Всё, что важно, — в одной платформе. Меньше рутины. Больше контроля».

На компьютере композиция разделена между текстом и схемой. На телефоне схема располагается под заголовком. Дальше посетитель проходит от проблемы к примеру импорта, экосистеме, возможностям Личного и Бизнеса, безопасности, дорожной карте и команде ogma.

Эффекты: фон canvas, реагирующий на курсор; нажатие на ядро; магнитные CTA; небольшой 3D-наклон карточек; появление секций; закреплённая схема экосистемы на широких экранах; анимированные SVG-связи; печать последнего слова в hero; появление демо-операций. Непрерывные эффекты отключены для сенсорных устройств, а canvas также отключён на ширине меньше 1000 px. В режиме reduced motion отключены анимации, магнитные эффекты, печать, canvas, плавная прокрутка и закрепление схемы.

## Локальный просмотр

В PowerShell перейдите в папку `multiknopka` и запустите:

```powershell
py -m http.server 8080 --bind 127.0.0.1
```

Откройте <http://127.0.0.1:8080/>. Для остановки сервера нажмите `Ctrl+C`. Подойдёт любой локальный статический HTTP-сервер. Python нужен только для просмотра и не нужен на сервере публикации. Открытие `index.html` двойным щелчком не подходит: браузеры ограничивают ES-модули и внешний SVG-спрайт при `file://`.

Для мобильного вида откройте DevTools → Toggle device toolbar (`Ctrl+Shift+M`) и задайте ширину 360, 390 или 768 px. Проверьте меню, нажатие на ядро, импорт, повтор демонстрации, переходы по якорям и работу CTA. Демонстрация не открывает ваши файлы: она добавляет две заранее подготовленные примерные операции.

Для reduced motion: DevTools → меню ⋮ → More tools → Rendering → Emulate CSS media feature `prefers-reduced-motion: reduce`. Перезагрузите страницу. Фон, печать, плавная прокрутка, наклон и непрерывные анимации должны прекратиться; демонстрация импорта должна завершаться сразу. Переключение системной настройки во время просмотра тоже поддерживается. Затем верните эмуляцию в исходное состояние.

Отключите JavaScript и перезагрузите страницу: основной текст, модули и ссылки должны остаться видимыми. При навигации клавишей `Tab` появляется ссылка пропуска к содержимому; все ссылки и кнопки имеют видимый фокус. Мобильное меню закрывается клавишей `Escape` с возвратом фокуса на кнопку меню.

## Публикация и CSP

Разместите файлы в корне `https://multiknopka.ru/`. Приложение остаётся по адресу `https://app.multiknopka.ru`. Никакой серверный API для лендинга не нужен. Контакт и ранний доступ используют только `mailto:`.

В HTML включена строгая CSP через meta. В `server-headers.conf` — пример заголовков для существующего HTTPS-блока nginx. Заголовок на сервере дополнительно запрещает встраивание страницы через `frame-ancestors 'none'`, поскольку эта директива не применяется в meta. Не заменяйте существующую конфигурацию сервера целиком; перенесите нужные директивы в действующий блок. Если политика уже задана, согласуйте её с этим набором: несколько CSP применяются одновременно.

```text
default-src 'self';
script-src 'self';
style-src 'self';
img-src 'self';
font-src 'self';
connect-src 'self';
object-src 'none';
base-uri 'self';
form-action 'none';
frame-ancestors 'none'
```

Inline-скриптов, inline-обработчиков и inline-стилей в исходниках нет. Schema.org размечен через HTML microdata: `Organization`, `Person`, `SoftwareApplication` и `Offer` с ценой 0 RUB. Это не требует inline JSON-LD или ослабления CSP. Внешние ссылки не требуют добавления доменов в `connect-src`, поскольку сайт не загружает с них данные.

Ссылки `/privacy` и `/consent` намеренно ведут на ваши серверные маршруты. Тексты этих документов и реквизиты оператора не предоставлены, поэтому они не придуманы и не включены в комплект. Сохраните существующие утверждённые документы или разместите их до публикации. На простом локальном сервере Python эти два маршрута вернут 404 — это ожидаемое ограничение комплекта, а не скрытые заглушки. Они пока не добавлены в sitemap.

Сервер должен отдавать `.js` с корректным JavaScript MIME type, `.woff2` как `font/woff2`, `.svg` как `image/svg+xml` и `.png` как `image/png`. Включите gzip/Brotli для HTML/CSS/JS/SVG. Не используйте бесконечный immutable-кеш для `main.js` и `styles.css` без версионирования имён.

## Проверка перед публикацией

- [ ] Страница загружается по HTTPS; HTTP перенаправляется на HTTPS, сертификат действителен.
- [ ] В Console нет ошибок CSP, JavaScript и загрузки локальных шрифтов; все ресурсы в Network с того же origin.
- [ ] CSP сервера не содержит `unsafe-inline` или `unsafe-eval`; `frame-ancestors` задан именно заголовком.
- [ ] Главная, CSS, JS, SVG, WOFF2, PNG, `robots.txt` и `sitemap.xml` отдают 200 и правильные MIME type.
- [ ] `/privacy` и `/consent` содержат ваши утверждённые документы и отдают 200.
- [ ] Все CTA ведут на `https://app.multiknopka.ru`; в почтовой ссылке тема «Бизнес — ранний доступ».
- [ ] Бизнес помечен «Скоро», Склад и Интеграции — «В разработке», приложения Android/iOS — «В планах».
- [ ] Условные суммы и операции подписаны как демо. Нет фальшивых отзывов, счётчиков и логотипов партнёров.
- [ ] Проверены 360/390/768/1000/1440/3840 px, масштаб 200%, фокус, `Tab`, `Shift+Tab` и `Escape`.
- [ ] Проверен `prefers-reduced-motion`, в том числе переключение во время работы демо.
- [ ] Проверены title, description, canonical, Open Graph PNG 1200 × 630 и микроразметка.
- [ ] Запущен Lighthouse в Chrome DevTools: Navigation → Mobile, чистый профиль без расширений, три прогона. Цель — не ниже 90. Сохраните медианный результат после размещения и настройки сжатия.
- [ ] Обновлены sitemap и canonical, если сайт будет опубликован на другом домене.

Lighthouse в этой среде не установлен: оценка 90+ не измерена и не заявляется как полученный результат. Устойчивые 60 fps также требуют проверки на целевых устройствах. В коде ограничены число точек, разрешение canvas и частота кадров; отрисовка приостанавливается вне hero и в скрытой вкладке. Это меры производительности, а не обещание результата на любом устройстве.

Фактически проверены: синтаксис ES-модуля; работа ядра; импорт, пересчёт и сброс демонстрации; мобильное меню; отсутствие горизонтального переполнения на перечисленных ширинах; отсутствие ошибок JavaScript/CSP в браузере. Итоговые размеры файлов и результаты статической проверки находятся в отдельном отчёте комплекта.
