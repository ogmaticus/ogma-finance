# Пункт 3.8 — импорт, версия 1.9.9

Три явных шага: загрузка, проверка, готово. На проверке — одна сводка найденных операций и записей, требующих внимания. Недостающие дата, тип, счёт, валюта, рублёвая сумма и основные данные исправляются прямо в строке. Счёт и дата для всех остаются доступными. Причина недоступной кнопки добавления написана в нижней панели; есть «Указать одну дату для всех». Чекбоксы 24 px с областью нажатия 44 px. Распознавание показывает превью, прогресс и отмену.

После добавления — экран подтверждения с переходом к операциям и загрузкой ещё. Автоматическое сопоставление счёта по последним четырём цифрам, категории банка и различение дат/дневных итогов сохранены.

Исправлено найденное сравнение дубликатов после перехода на копейки: сравниваются amountMinor либо переведённая сумма черновика. Похожие записи требуют подтверждения; одинаковые настоящие покупки не удаляются автоматически.

Новые тесты: три шага, причина блокировки, исправление полей, недопустимая календарная дата, выбор счёта, сумма с запятой, сравнение дубликатов в обоих форматах, завершение и повторный импорт. Старые проверки дат, категорий, переводов, сохранности исходников и двойного нажатия проходят. Полный набор проверок, TypeScript, ESLint, форматирование и сборка обязателен перед публикацией.

Изменены import-ui.js, app.js, state.js, events.js, shell.css, e2e-сценарий, тесты и версия. Данные пользователей не сбрасывались, SQL/формат бюджета не менялся.

Браузерный OCR с настоящими изображениями под CSP, Android и Safari здесь не проверены. Нужно проверить распознавание, отмену, превью, изменение даты/счёта, нижнюю панель с клавиатурой, оба оформления и экран завершения.
