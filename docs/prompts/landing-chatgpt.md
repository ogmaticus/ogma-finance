## Технические требования (строго — сайт будет на нашем сервере со строгой защитой)
- Чистые HTML + CSS + JavaScript (ES-модули), **без фреймворков и сборщиков**, без npm. Файлы: `index.html`, `styles.css`, `main.js`, папки `assets/` (SVG, изображения) и `fonts/`.

Шрифты подключи локально через `@font-face` (woff2 в `fonts/`, укажи, какие файлы скачать с официальных источников Rubik и IBM Plex Sans, лицензия OFL).
- Адаптивность: от 360 px до 4K, mobile-first. Доступность WCAG AA: контраст, фокус с клавиатуры, alt, семантика, `lang="ru"`.
- Производительность: Lighthouse ≥ 90 на мобильном; вес страницы без шрифтов ≤ 500 КБ; изображения SVG/WebP, ленивая загрузка; анимации на transform/opacity.

- Никаких cookie и трекеров; формы — только mailto.
- Весь текст — на русском, живым простым языком, без канцелярита и без преувеличений.
