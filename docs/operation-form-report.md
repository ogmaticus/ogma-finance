# Пункт 3.9 — форма операции, версия 1.9.10

На телефоне форма — нижняя шторка. Сверху переключение расход/доход/перевод/возврат, крупная сумма с decimal-клавиатурой и автофокусом. Принимаются точка и запятая. Категории — сетка SVG-иконок, недавно использованные первыми. Название и комментарий, быстрые даты «Сегодня/Вчера/Выбрать», счёт и время в «Ещё». Для перевода блок счетов раскрывается автоматически. Сохранение закреплено внизу на всю ширину.

Счёт по умолчанию определяется по последней изменённой операции с действующим счётом, затем по дате и времени. Это не требует нового поля бюджета. Дата нового ввода сохраняет ранее исправленное правило: сегодня для текущего месяца, последний день для другого месяца. Чипы явно позволяют выбрать сегодня/вчера. Возвраты поддерживаются отдельно, ранее добавленные данные сохраняются при редактировании. При сохранении другого месяца переключатель показывает этот месяц.

Ошибки суммы, даты и счетов отображаются в форме. Перевод на тот же счёт не сохраняется. Нажатие операции из истории категории сначала закрывает её диалог.

Проверки: недавние счета/категории, отсутствующий удалённый счёт, дата на границе года, тип перевода и блок счетов, сохранность бюджета при ошибке, суммы с точкой/запятой, комментарий и редактирование без дублирования. Общие тесты, TypeScript, ESLint, форматирование и сборка обязательны перед публикацией.

Изменены operation-form.js, app.js, app.html, events.js, shell-ui.js, shell.css, тесты и версия. Серверный формат и SQL не менялись.

Не проверено на Android/Safari: автофокус и клавиатура, видимость сохранения, сетка категорий, даты, смена типа и анимация шторки.
