## Изменения завершающего шага

Базовые стили вынесены из app.html в base.css. Цвета, шрифты, отступы и радиусы находятся в design-tokens.css; appearance.css и shell.css используют их. Сохранены совместимые токены прежних экранов. Новые категории и формы используют ограниченную семантическую палитру. Поля ввода используют размер 17 px; крупная сумма — 34 px. Чекбоксы 24 px находятся в области нажатия 44 px; остальные основные элементы имеют минимум 44 px. CSS декларации не подтверждают фактическую геометрию браузера, она ещё не измерялась.

Включён viewport-fit=cover и безопасные отступы. Сохранены анимации диалогов и режим уменьшения движения. История операции из категории корректно закрывает родительское окно перед редактированием. Даты дневных заголовков приведены к виду «7 октября, среда».

Добавлен test-design-contract.mjs: определения всех используемых CSS-переменных, единственный источник цветов/типографики, шкала 13/15/17/20/28/34, порядок CSS, фокус/reduced-motion/safe-area. Проверка контраста расширена до 28 сочетаний в светлой/тёмной теме, все не ниже 4,5:1. Это проверки выбранных токенов, а не полный браузерный аудит каждого элемента.

В CI добавлены форматирование и сборка. E2E адаптированы к новой навигации, бюджету и завершению импорта; проверка --list регистрирует 8 сценариев (390×844 и 1440×900). Их выполнение в браузере не проведено; запуск GitHub CI не подтверждён.

## Сохранность

Работа велась на тестовых данных. Данные пользователей не сбрасывались, SQL-миграции не переписывались. Формат бюджета остаётся schemaVersion 3, суммы — целые копейки, ZIP версии 1.6 по-прежнему читаются. Синхронизация, снимки, удаление и архивирование исходников проходили общие регрессионные проверки на каждом шаге. Дополнительно исправлено сравнение дубликатов импорта в копейках; похожие записи подтверждаются, а не удаляются автоматически.

## Проверки перед итоговой публикацией

Полный npm test (все Node/модульные/DOM-модели/серверные регрессии плюс TypeScript), ESLint, Prettier и сборка обязательны перед публикацией. Публикация только после их успешного завершения. Доступность HTML и новых ресурсов проверяется отдельно после публикации.

## Что остаётся непроверенным

1. Визуальный проход на Android и iPhone Safari: 390 px, длинные суммы/названия, клавиатура и закреплённые кнопки, нижняя панель, диалоги, темы, планшет/десктоп.
2. Настоящий OCR/wasm/worker под CSP: загрузка реальных банковских скриншотов, даты и дневные итоги, отмена, офлайн-распознавание и исходники после обновления.
3. Браузерный прогон Playwright и подтверждённый запуск CI.
4. Обновление установленной PWA с сохранением бюджета и незавершённого импорта на реальном устройстве.

В этой управляемой среде предусмотренный Sites браузер для проверки недоступен. Эти пункты нельзя считать закрытыми только по автоматическим Node-тестам. Таким образом, программная реализация оставшихся пунктов выполнена, но полная приёмка всего задания пока не завершена.
